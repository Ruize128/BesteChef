# BesteChef

This is the assignment for course Human-Computer Interaction.

## Running

For MacOS version, unzip the file and open the .app directly.
Note: macOS may block unsigned apps because we don't have a developer ID yet. If double‑clicking is blocked, right‑click (or Control‑click) the app in Finder and choose "Open", then click "Open" in the dialog. 
If that still fails, open `System Settings → Privacy & Security` and click "Open Anyway" (or "Allow") in the Security section. Only follow these steps if you trust this app.

This app has been carefully designed; the desktop version (MacOS) does not create local data storage. After testing, simply close it and delete the .app file.
